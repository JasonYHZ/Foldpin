# Foldpin 0.1.1

A bug-fix release for Shortcuts settings. Version **0.1.1**, build **3**.

## Fixed

- Fixed the **In App / Global** selector overlapping the native settings toolbar and becoming unclickable.
- The scope selector, descriptions, shortcut groups, and footer now share one scroll layout below the toolbar.
- Note formats and existing shortcut preferences are unchanged.

## Download and upgrade

Requires **macOS 26.5 or later**. One universal app supports **Apple Silicon (arm64)** and **Intel (x86_64)**.

Download `Foldpin-0.1.1-universal.dmg`, open it, and drag **Foldpin.app** to **Applications**. Back up your complete note library before upgrading. The ZIP contains the same application.

**Signing:** Ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the download source, check **System Settings → Privacy & Security → Open Anyway**, subject to system policy. Do not disable system-wide security protections.

## Homebrew

After this release is published and the project-maintained Cask is updated:

```sh
brew update
brew upgrade --cask jasonyhz/foldpin/foldpin
```

For a first installation:

```sh
brew tap jasonyhz/foldpin https://github.com/JasonYHZ/Foldpin.git
brew install --cask jasonyhz/foldpin/foldpin
```

This is a project-maintained tap, not an official Homebrew Cask listing.

## Validation and limitations

The targeted isolated native regression passed for English/Chinese, light/dark appearances, two window sizes, and both scope directions. Debug compilation passed. Release checks cover universal architectures, signature integrity, bundled translations, corresponding source, archive integrity, and checksums.

Intel hardware, minimum-OS hardware, fresh-user first launch, downloaded-app Gatekeeper behavior, upgrades, live recording/playback, and full VoiceOver coverage remain unverified.
