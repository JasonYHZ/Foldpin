# Foldpin 0.1.0

The first regular release of Foldpin, a native macOS app for floating sticky notes. Capture ideas in independent windows, pin references beside your work, and shelve notes to find them later.

The packages were rebuilt for public distribution after repository privacy cleanup. Compiler source paths and the configured development-team identifier were removed; application functionality and the note format are unchanged. Use the current SHA256SUMS and build-info.json; earlier downloads have different checksums.

## Requirements and installation

- **macOS 26.5 or later.** One universal app includes Apple Silicon (arm64) and Intel (x86_64).
- Download **Foldpin-0.1.0-universal.dmg**, open it, and drag **Foldpin.app** to **Applications**. The ZIP contains the same app.
- Back up your complete note library before upgrading. The application version is **0.1.0**, build **2**.

**Signing:** This app is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the download source, check **System Settings → Privacy & Security → Open Anyway**, subject to your system policy. Do not disable system-wide security protections.

## Included features

- Independent notes with pinning, collapsing, desktop arrangement, shelving, search, and Recently Deleted.
- Native block editing with headings, lists, tasks, tables, code, images, link cards, and Markdown paste.
- Local recording, audio/video/file attachments, and Markdown/HTML export.
- Paper and Liquid Glass appearance, light/dark themes, note colors, fonts, and custom shortcuts.
- English, Simplified Chinese, Traditional Chinese, Japanese, Korean, German, French, and Spanish interfaces.
- An optional local MCP server with client authorization and access controls, disabled by default.

This release keeps the feature scope of Preview 1 and adds English-first repository documentation with a linked Chinese README. Notes and attachments stay local; link previews request their target websites, and authorized external MCP clients control their own subsequent use of permitted content. Cloud sync, built-in AI organization, and transcription are not included.

## Validation and known limitations

310 automated tests pass in serial execution. Universal compilation, signature integrity, compiled translations, corresponding-source hashes, package integrity, and release checksums are checked before publication.

Intel hardware, minimum-OS hardware, fresh-user installs, downloaded-app Gatekeeper behavior, and upgrade flows have not completed manual validation. Live recording/playback and full accessibility coverage also remain unverified. The regular release label does not imply Apple notarization or completion of every planned feature.
