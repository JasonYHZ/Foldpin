# 粘贴网址与链接卡片

2026-09-16，按用户要求接入。没有创建新分支。

## 使用

- 在空白正文段落粘贴完整 HTTP / HTTPS 网址，或选中整个正文段落后粘贴网址，立即生成可点击的链接卡片，并在后台获取网页标题、两行简介、站点信息和网页封面缩略图。左侧封面、右侧信息，底部显示含路径的实际网址；窄窗口换行，超长地址省略并保留完整悬停提示。卡片后保留可继续输入的段落。
- 在句子中粘贴网址，或粘贴含网址的普通文字，自动识别为行内超链接。保留原有样式和显式 Markdown 链接；代码块、行内代码和「粘贴为纯文本」保持原文。
- 单击卡片在默认浏览器打开原网址；卡片的区块菜单支持「打开链接」「刷新链接预览」「转为文字链接」，以及既有复制、副本、移动和删除。
- 网页信息不可用时保留网址和打开能力，不阻断输入。无标题、需登录或依赖 JavaScript 的网页可能只显示域名、网址；不执行网页脚本、不登录网站。

## 保存与交互

`NoteBlockKind.linkPreview` 和可选 `NoteBlock.linkPreview` 保存原网址、标题、摘要、站点名及获取状态；可选 imageURL 与 thumbnail 保存封面来源和经过降采样的 JPEG。旧卡片仍可读取，使用「刷新链接预览」获取新增的封面信息。旧纸片的缺省字段仍兼容。重开纸片不自动联网，已经获取的信息离线可用；中断的请求可由区块菜单刷新。

`BlockTextCodec` 用一个带链接属性的原生 TextKit 附件渲染卡片，共用纸片墨色与现有编辑器。固定 184 点高度，元信息和封面更新不推移后续正文。正文与收纳窗口编辑区域使用同一路径。

`PaperTextView` 将粘贴作为一次原生撤销操作；异步元信息只更新附件属性，不另插入撤销项，不替换编辑器。结果按区块 UUID、网址与请求令牌核对；撤销、删除或更换区块后丢弃过期响应。组合输入、图片标题和缩放期间延后应用结果。当前编辑器内缓存最多 128 个网址，原生重做恢复占位时可复用结果。纸片保存仍经过 `onContentChange` 的既有错误保护。

结构复制保留卡片数据，纯文本复制保留网址，富文本 / HTML 复制保留可点击链接。Markdown / HTML 导出包含标题链接、简介和实际网址，不要求重新联网。带封面的卡片会将 JPEG 与正文打包为 ZIP，正文引用 assets 内的封面；没有封面的单张纸片仍可直接导出文本文件。结构复制与 HTML 复制保留图片；RTFD 将图文卡片作为可点击图片携带，纯文本保留网址。

## 网络与边界

`LinkPreviewFetcher` 使用临时 URLSession，不带 Cookie、凭据或磁盘缓存，不经过第三方预览服务。只接受 HTTP(S)、禁止网址内嵌用户名密码，重定向复查协议并拒绝 HTTPS 降级。每次粘贴最多排队 32 个任务，同时最多 3 个请求；每个请求 / 资源超时 10 / 15 秒，HTML 上限 1 MiB，同时检查声明长度和实际接收量。

读取 HTML 的 Open Graph / Twitter / title / description，清理注释和 script/style，解码常见字符实体及数值实体。根据最终页面地址解析相对封面 URL，只获取一张封面，禁止非 HTTP(S)、含凭据或 HTTPS 降级的图源。封面下载上限 4 MiB，尺寸上限 40 百万像素；ImageIO 降采样至最长边 640 像素、保存不超过 160 KiB 的 JPEG，去除原始元数据。缩略图随纸片 JSON 保存，不依赖临时文件，渲染使用有界缓存。图片下载或解码失败仅回退文字卡片。无网站图标下载、WebView 或远程脚本执行。说明：这不是离线网页归档，也不保证所有站点都提供有效元信息。

### 文字链接与卡片双向转换

- 文字右键和区块菜单增加「转为链接卡片」，支持带名称的超链接和普通 HTTP(S) 网址。右键优先按指针定位链接；同段多个链接时按指针／光标／所选链接确定目标，不默认转换第一个。
- 转换仅替换目标链接，前后正文、其他链接及文字样式保留为相邻区块。菜单绑定来源区块快照，正文已变化时拒绝过期动作；只读、代码和组合输入保持原保护。
- 卡片保存可选 `textLabel`；转回文字时恢复原链接名称和网址。当前编辑器内来回切换复用已保存的标题、摘要和图片，原生撤销／重做包含完整转换；缓存不共享各个链接自己的名称。
- 增加 7 项双向转换回归，覆盖菜单入口、裸网址、跨格式链接、多个链接的定位、Unicode 与前后格式、一次撤销、离线图片复用、持久化标签、过期／只读／组合输入保护和请求失败后的缓存隔离。

### 卡片多余矩形与底线修正

- 编辑器内的卡片不再给整个 TextKit 附件添加 `.link`，避免原生链接装饰在圆角外绘制底线；显式清空文字背景和下划线，保留圆角描边、网址提示与指针样式。点击继续按区块命中区域打开网页，普通行内链接保持原样。
- RTFD 复制时单独为导出的卡片图片添加链接，外部富文本仍可打开原网址。
- 在原生 NSTextView 中复现附件链接的底部下划线；使用实际 PaperTextView 在有色背景上检查修正后的圆角、透明背景与底部。21 项链接／双向转换／上下文菜单回归及一次临时编辑器截图检查通过，Debug 构建通过。临时检查未保留在测试集，也未重启用户应用。
