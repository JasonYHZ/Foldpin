# 外观个性化 · 第一、二阶段实现记录

2026-09-24 后续决定：下文第一阶段的「阅读底色 14% 默认值」是当时的实现记录；当前滑杆默认显示玻璃平衡 50%（内部 `glassBalance = 0`），详见文末的双向控制说明。

日期：2026-09-22。依据：英文 PRD。

## 已实现

- 保留独立的主题与纸感／通透选择。通透改用「玻璃样式」「阅读底色」「颜色强度」三个明确入口；纸感单独显示「纸面不透明度」。不提供虚假的连续模糊度滑杆。
- 阅读底色仍保存为 `glassOpacity`，沿用旧值与 14% 默认值。0% 仅去掉中性底色，保留原生玻璃和既有点击支撑底层；正文与控件不随之透明。
- 新增 `glassColorIntensity`，默认 100%。原生窗口和 SwiftUI 预览共用 NotePalette 的强度计算；0% 时原生 tint 返回 nil、额外色层也消失，100% 保持原有 tint 和 18% 色层。原色始终不染色，纸片颜色元数据不变。
- 双材质预览使用合成文字、细线、明暗区域及蓝色示例纸片，包含标题、短句、待办和代码；不读取用户纸片或桌面。预览沿用生产材质及辅助功能回退。
- 「恢复材质默认设置」仅恢复纸感、标准玻璃、100% 纸面、14% 底色和 100% 染色，保留主题、字体及已有纸片颜色。移除原来含糊的全组外观重置。
- 保留 `noteStyle.v1`；旧 JSON 按字段读取，缺失／无效字段单独使用默认值，数值越界夹取，不因新增字段重置其他选项。未改动笔记文件格式。
- 新文案含简体中文和英文，辅助功能覆盖时禁用相应控件并说明偏好仍被保存；滑杆提供可读名称和百分比。

## 第二阶段：日常个性化（2026-09-24）

- 标题栏增加「自动／始终显示」。始终显示复用现有关闭、置顶、折叠、收起和图标入口；自动模式仍由鼠标、焦点、操作面板和 VoiceOver 控制。标题栏高度保持 52 点，不改变原生拖动区域。
- 内容密度增加「紧凑／标准／舒适」。共享间距参数控制区块、代码外围、正文上下及底栏留白；标准保持原值。媒体控件、表格单元格、块手柄、窗口边缘和字体大小不缩小。现有编辑器收到偏好通知后原位重排，中文组合输入结束前延迟刷新。
- 新建纸片默认颜色使用现有六色。普通新建、快捷键、收纳窗口新建、快速录音，以及没有颜色元数据的 Markdown 导入使用此默认值；显式颜色与复制来源颜色优先。已有、恢复和复制的纸片不重着色。
- 新建尺寸提供小 300×260、标准 360×340、大 460×440 三档，按可见屏幕限制。新纸片创建时记录初始尺寸档位，之后从收纳首次打开仍用创建时的档位；已有 frame、显式尺寸及复制来源尺寸优先，后续修改默认值不改变已有纸片。
- 正文字段改名「额外行间距」并显示点数。材质、标题栏和密度、正文字体、代码字体、新建默认值分别重置；代码主题文件不受字体重置影响。`noteStyle.v1` 继续逐字段兼容旧偏好。

## 2026-09-24 预览材质修正

纸感示例改用默认暖色纸面，玻璃示例继续使用蓝色以展示染色强度。示例玻璃现在仅铺在卡片背景；纸面和玻璃阅读底色独立覆在背景上，文字、图标与控件不再放进玻璃效果本身。这样纸面透明度只让示例背景透出，阅读底色从 0% 到 100% 能直接改变玻璃上的遮挡程度。原生纸片的纸面填充仍只绘在编辑器背后；独立原生渲染检查确认 20% 与 100% 纸面时示例墨迹都保持不透明。

## 2026-09-24 玻璃双向控制

用户最终确认以滑杆 50% 作为原生玻璃基点：左侧 0% 至 50% 只减弱原生玻璃层，右侧 50% 至 100% 只增加文字背后的阅读底色。左侧同时减弱持久选色底纹；整个窗口、编辑器、标题栏与控件始终保持不透明。为此，原生 NSGlassEffectView 改为编辑器后面的独立背景，编辑器保持同一个宿主视图，不再在切换材质时重新挂载。玻璃层不参与命中测试；最低端仍保留原有 2% 原生点击支撑底层。

系统只公开「标准／清澈」两档 NSGlassEffectView 样式，没有连续模糊半径。双向滑杆控制的是玻璃层可见程度与阅读底色，不标成模糊度。偏好仍编码为 `glassBalance`，内部 −1…1 映射到滑杆 0%…100%；旧的正数 `glassOpacity` 逐值迁入。新安装和材质重置的内部值为 0，即滑杆 50%；旧用户明确保存的数值保留，显示刻度变化不改变实际效果。辅助功能要求实色时，滑杆停用但偏好保留。

原生窗口的透明度层次、背景与内容分离、偏好迁移、设置布局均有隔离检查；真实桌面的最左端点击、跨屏拖拽、失焦合成和对比度仍需实机验收。
