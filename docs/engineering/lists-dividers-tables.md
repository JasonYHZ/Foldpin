# 有序列表、分隔线与原生表格

2026-09-08，用户要求在项目符号列表下增加有序列表，并支持 `---` 分隔线与表格插入。

2026-09-09：单元格右键菜单支持上方 / 下方增行、左侧 / 右侧增列和删除当前行列，至少保留一行一列。新行列进入编辑，全部可撤销；标题行列按位置生效。详见[区块操作](block-actions.md)。

## 使用方式

- **有序列表**：在项目符号列表的下一项；行首输入 `1.` 加空格也可创建。非空项回车续号，空项回车 / 项首退格退回正文。连续有序块从 1 编号，移动、复制、删除或拆开列表后按当前位置重新编号；编号属于显示，不混入 block.text。
- **分隔线**：从 `/` 或底部区块菜单插入，也支持行首 `---` 加回车或空格。转换后光标进入下一正文块；不会把粘贴内容、句中标点或组合输入自动改成横线。非空块中从菜单插入时保留原文，在后方新增独立分隔线。
- **表格**：从 `/` 或底部区块菜单插入空的 2 列 × 3 行网格，直接进入第一个单元格。点击单元格可编辑，Tab / Shift-Tab 按行切换，最后一格按 Tab 自动加一行。Enter 在单元格中换行，⌘Return / Esc 回到表格后的正文。悬停或编辑时，底部「＋」增加行、右侧「＋」增加列，并进入新单元格。六点菜单可添加行 / 列、切换标题行 / 标题列，也可复制、创建副本、移动和删除整张表格。

表格当前是普通文本单元格，行高随内容增加，列宽均分纸片可用宽度。标题行 / 标题列使用较粗文字与轻底色，开关可保存与撤销。尚无合并单元格、列宽拖动、拖动加号增减、单元格富文本或数据库功能。表格和分隔线使用插入语义，不放进会丢失原内容的「转换为」子菜单。

## 原生实现与存储

正文继续使用同一个 NSTextView + TextKit 2。表格网格由原生附件绘制，每个纸片最多额外保留一个正在编辑的原生单元格 NSTextView，其他单元格不各自创建编辑器。没有 WebView，也不修改语法引擎。考虑到 Apple 在 [TextKit 迁移说明](https://developer.apple.com/videos/play/wwdc2022/10090/)中描述过 NSTextTable 的兼容模式限制，这里不依赖传统 textBlocks 表格布局。

表格为 `NoteBlock(kind: table, table: { rows: [[String]], headerRow: Bool, headerColumn: Bool })`，分隔线为 `NoteBlock(kind: divider)`，有序项为 `orderedList`。表格单元格的换行与 Unicode 原样保存，网格几何与颜色不写正文；附件元数据只作为编辑表面和数据模型的桥接。NoteContent 继续使用 schema 1 / NoteDocument v2，新增可选 table 字段兼容旧文件，旧表格缺少两个标题开关时按 false 解码，旧块的原始值不变。校验拒绝空行列、参差行、错误类型附带 table 数据或非法正文；写入失败保留原文件。

每次单元格文字变化更新一份不可变附件快照，通过宿主原生 insertText 进入相同 UndoManager，并发布到现有本地保存流程。更新不会销毁活动单元格，不重置其输入法标记和选区；撤销 / 重做后同步当前单元格。切换明暗或恢复纸片继续保留当前编辑器。整块复制在应用内携带结构化 JSON，对外提供制表符分列的文本；多行单元格暂不提供 CSV 转义或电子表格导入。
