# 本地录音与音频块 · 2026-09-09

用户确认先加入纸片内录音和播放。本轮实现原音频的本地录制、导入与播放；语音转写、AI 整理与云端处理仍为后续方向。

## 使用

- 正文输入 `/`，在媒体组选择「录音」或「导入音频…」。原生插入区块菜单提供相同入口；音频文件也可单个拖入或粘贴到正文。
- 首次主动录音时才请求麦克风权限。录音条显示实时音量波形、已录时间、暂停 / 继续、完成。失焦继续录音；折叠、收纳、删除纸片或退出前结束并保存，失败时阻止隐藏。
- 播放条高 64 点：左侧 32 点播放 / 暂停，中间可点击和拖动的波形，下面显示当前位置 / 总时长。宽度不足 270 点时隐藏独立倍速按钮，仍可从更多菜单选 1×、1.25×、1.5×、2×。
- 更多菜单提供倍速、重命名、导出、删除区块。全应用同时最多一段录音或一段播放，录音开始会暂停播放；播放录音不会自动启动麦克风。
- 操作色跟随纸片墨色，录音使用红色。语言切换刷新播放器文案；录音名称作为用户内容保留。

## 数据与实现

`NoteBlockKind.audio` 与可选 `NoteBlock.audio` 沿用 JSON v2 / content schema 1。旧笔记无 audio 字段仍可解码；缺失元数据、非法扩展名、非有限时长或波形值会被拒绝。`NoteAudio` 保存独立资产 UUID、名称、扩展名、秒数、至多 128 个归一化波形值和未完成标记。

录音由 AVAudioRecorder 写入本地 `assets/<UUID>.m4a`，AAC、44.1 kHz、单声道、64 kbps。先准备文件、插入并保存草稿，成功后才启动录音。正常完成时停止编码，读取实际时长，把限量保留的计量采样合成波形，再沿用编辑器原生撤销与 NoteStore 原子保存。异常或撤销恢复后的未完成录音可点击恢复按钮尝试读取并完成；若文件本身不可解码，显示错误并保留原文件，不能保证进程崩溃中断的 M4A 必然可恢复。

导入支持系统可解码的 M4A、MP3、WAV、AIFF、CAF、AAC、FLAC，单文件不超过 500 MB。后台复制到本地资产目录，再用分块解码生成时长 / 波形；不改源文件。异步结果绑定原块快照，块已改变或处于组合输入时拒绝插入。波形采样和音量计量为显示用途，不是音频分析精度承诺。

`AudioTextAttachment` 在 NSTextStorage 中只占一个附件字符。`PaperTextView` 用 TextKit 的 `frameForTextAttachment` 定位可见的原生 NSHostingView 播放条；按块 UUID 复用，布局 / 滚动合并更新，离开视口释放视图，播放器状态仍由独立模型保存。初版自动 view-provider 方案在不可见原生编辑器检查中未出现子视图，已移除；不依赖该方案显示播放器。无 WebView，不为每段音频创建正文编辑器。

进度与实时波形使用 0.1 秒计时器，只更新该播放器的观察状态，不写 NoteStore、不刷新全文、不产生每一帧撤销。正常编辑、重命名、完成录音、复制、排序、删除与撤销保留原生编辑机制。区块 / 纸片删除不会清理音频资产，以支持撤销、创建副本和最近删除恢复。

整张复制或选区包含音频时，Foldpin JSON 保留结构，RTFD 包含真实音频文件，HTML 内嵌音频并附名称 / 时长。复制前完成活动录音，缺文件或生成失败时保留旧剪贴板；音频合计超过 32 MB 时提示使用导出，避免富文本复制产生大量编码副本。外部应用是否播放这些格式取决于接收方。Foldpin 内部粘贴须能在本地资产目录找到音频，不能把任意来源路径当成读取目标。

## 权限与验证边界

Xcode 使用 `ENABLE_RESOURCE_ACCESS_AUDIO_INPUT` 生成 `com.apple.security.device.audio-input`，用户选择文件为 read-write，以允许 NSSavePanel 导出。麦克风用途说明通过 InfoPlist.xcstrings 打包中英文，不申请系统音频捕获或屏幕录制权限。无联网或上传。

新增 8 项音频检查使用合成 WAV、临时文件、专用命名剪贴板与不可见原生窗口，覆盖波形与时长、源文件保护、无效元数据、缺文件保存保护、附件往返、原生撤销、重命名选区保持、真实 RTFD 音频字节、删除恢复、草稿完成及失败保留、窄 / 常规播放条渲染、正文内原生视图定位。已有菜单测试更新为包含两个音频动作的键盘循环，最终全量 178 项通过。常规、窄宽度与录音态播放条均已检查离屏截图。

最终 Debug 构建成功，打包后的中英资源和麦克风用途说明已核对，签名包含音频输入和用户选择文件读写 entitlement。实机麦克风授权 / 拒绝、实际录音音质、播放设备切换、长时间录音、真实鼠标拖动进度、VoiceOver 体验仍需从当前 Xcode 运行新版检查。本轮没有录制用户声音、打开真实纸片或操作通用剪贴板。离屏截图与自动检查不能代替这些实机验收。

临时检查日志：`/private/tmp/foldpin-audio-regression.log`、`/private/tmp/foldpin-audio-native.log`、`/private/tmp/foldpin-audio-xcode.log`。图形实现参考了 Apple 的[文本附件文档](https://developer.apple.com/documentation/appkit/nstextattachmentviewprovider)，最终使用既有表格的附件几何定位路径。
