# 单块选择与操作菜单

2026-09-08，用户确认先实现六点手柄、单块选中和操作菜单，随后要求补齐拖动排序。参考此前提供的[块操作截图](../design/native-block-menu/reference-block-actions.png)。

## 当前行为

- 鼠标移到区块时，左侧显示一个六点手柄；移动到别的块时复用该控件。正文水平留白调整为 32 点，为手柄留出空间，与窗口左侧缩放边缘分开。
- 按住手柄移动至少 5 点，启动系统原生拖动，显示内容摘要和蓝色插入线。松开后整块移动，拖到上下边缘自动滚动；Esc 或拖出编辑区取消。正文、列表、代码、分隔线、表格和图片均按整个区块移动。
- 点击手柄选中整块，显示浅蓝色整行区域并打开系统原生菜单：转换为、复制区块内容、创建副本、上移、下移、删除。图片可复制、创建副本、移动和删除，不能直接转换为文字而丢失附件。
- 自动换行和 Shift+Enter 仍属于原来的块；多行代码、图片分别按整个块定位。正文仍共用一个 NSTextView，不为各块创建独立编辑框。
- 点击正文回到普通光标编辑。选中块时，上下方向键切换单块选择；Enter 进入块末尾编辑，直接输入或粘贴也进入末尾，不覆盖整块原文。图片后继续输入会进入后方正文。
- Esc 先取消块选择，再次按下才沿用纸片收纳；取消图片选择不产生新内容。Backspace / Delete 删除选中的整个块，包括带修饰键的删除，避免误删邻块文字。
- 选中块时支持 ⌘C 复制、⌘X 剪切、⌘D 创建副本、⌘⌥↑ / ↓ 移动。复制同时提供纯文本和 Foldpin 结构化剪贴板数据；图片在 Foldpin 内沿用附件引用。剪切须先复制成功才删除。
- 菜单转换、创建副本、移动、删除继续使用原生 UndoManager；最后一块删除后留下一个空正文。删除图片块不清理附件文件，创建副本只生成新的块 ID。

多块选择、跨纸片拖动、嵌套列表仍未实现。界面没有假拖动反馈、页面链接或尚未支持的区块类型。

## 实现约束

「转换为」子菜单和既有内容块菜单统一使用类型图标：正文 T、标题 H₁–H₄，其余沿用斜杠菜单的系统图标。`BlockMenuIcon` 缓存原生模板图片，选中、禁用及明暗外观的图标着色交给 NSMenu；不替换系统勾选标记。

`BlockHandleButton` 是每个编辑器复用的一个 NSButton，位于 NSScrollView 上层，与 NSClipView 同级。滚动和布局合并定位更新，不在每次通知中先隐藏再显示，也不反复注册跟踪区域。切换语言更新现有控件标签，鼠标移动不重复发送相同标签更新。

TextKit 2 提供块和第一行的几何信息；只有可见块参与手柄定位。`selectedBlockID` 属于临时编辑状态，不写入 JSON。块选择使用独立高亮和隐藏插入光标，点击正文、全选、撤销等操作恢复文字选择模式；不把蓝色背景写进字符属性。

菜单每一项绑定明确的块 ID，执行时重新查找并校验，不能依赖原来正文光标所在位置。过期 ID、只读状态、组合输入期间拒绝结构操作。主题或异步语法着色不取消块选择；组合输入开始前回到普通编辑状态。

拖动使用 NSDraggingSession，私有拖放类型只携带本次 UUID 令牌，目标同时校验源手柄身份与会话，仅接受当前编辑器内移动。原来的图片和文本拖入保持原路径。依据 Apple [拖放执行说明](https://developer.apple.com/documentation/appkit/nsdraggingdestination/performdragoperation(_:))，正文变更只在 performDragOperation 执行；源会话结束时清理临时状态。

落点存目标块 ID（nil 表示末尾），根据整块高度判断上半区 / 下半区；向下移动扣除源位置，原位和邻接不重复保存。按下期间冻结手柄目标，短距离点击仍打开菜单。指针移动只验证索引与绘制落点，不复制块数组、不解析代码、不重新生成正文。边缘滚动定时器仅在拖动期间运行，退出、取消或视图释放后清理。文档结构被外部更新、目标过期、只读或组合输入时拒绝移动。

`replaceDocument` 继续负责同一个原生撤销栈与正文发布，拖动落下生成一次「移动区块」撤销操作。默认字符样式显式设置粗体 / 斜体为 false、删除线为 0，避免原生富文本插入继承光标格式而污染区块。没有新增存储字段、迁移文件或执行附件清理。
