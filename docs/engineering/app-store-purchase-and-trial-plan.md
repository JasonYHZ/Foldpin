# Mac App Store：7 天试用、买断与更新方案

日期：2026-09-14；状态：方案，未实现，未创建商店商品或提交审核。

## 1. 已确定路线

用户决定以 Mac App Store 收费和更新，提供 7 天试用，一次购买永久解锁，本应用后续更新不另收费。首版不做订阅、授权码、Foldpin 账号或自建收费后台。

建议商店结构：应用免费下载＋免费非消耗型 `7-day Trial`＋付费非消耗型永久解锁。商品 ID 在 App Store Connect 创建前固定；价格未决定，不硬编码币种或数额。界面读取 StoreKit 本地化商品价格。

Apple 审核指南 3.1.1 明确允许非订阅应用通过零价格非消耗型试用商品提供限时试用，需告知期限、到期功能限制和解锁费用。它不是订阅 introductory offer，也不是先付费下载再依赖退款试用。实施前在实际 Mac App Store 商品配置及沙盒验证零价格试用路径；该步骤是上线门槛，指南允许不等于此应用自动获批。

## 2. 购买和试用体验

欢迎页提供“开始 7 天免费试用”“永久解锁”“恢复购买”；试用不自动开通、不自动续费。确认领取 Apple 免费试用交易后开始计算，不从安装日期或第一次打开网页计算。

建议统一计时为已验证的原始领取时间＋168 小时，以明确到期时间展示，时区变化不延长。免费非消耗商品自身不会 7 天后失效，期限由 Foldpin 根据交易时间判断，不能只检查它存在就永久放行。换设备、重装和恢复购买不重置同一已领取交易的试用起点。退款／撤销的试用交易不得直接生成新试用资格。

状态：权益加载中、未领取、试用中、试用已结束、永久解锁、购买待批准、验证／网络异常。永久有效权益优先于试用状态；交易取消不报支付失败；pending 不提前解锁。

建议试用到期限制新建、编辑、导入、录音及管理写操作；始终允许已有内容查看、复制、导出和定位文件，不删除或加密用户资料。到期时先安全提交已经输入的内容、完成当前录音与已开始的保存任务，再限制新操作，不中途截断或丢失输入。具体付费边界需形成同一能力表供所有入口复用，包括全局快捷键和收纳编辑；未来 Agent 工具也不能绕过权益检查。

到期提示不反复抢焦点；点击受限动作才展示购买入口。导出等保留操作需要独立通道，不能因为“结束试用”而禁止其必要的保存收尾。

## 3. StoreKit 2 架构

建议 `PurchaseStore` 负责商品、购买和交易更新；`EntitlementStore` 负责已验证权益、试用时钟及能力状态；界面只观察结果，不散落购买布尔值。启动建立 Transaction.updates 监听，并读取 currentEntitlements；验证商品 ID、应用／环境、交易状态及撤销信息，成功交付权益后 finish 交易。

恢复购买提供明确按钮，用户触发时调用 AppStore.sync，再重新核对。不要每次启动强制同步弹出账号认证。首次购买、换设备恢复及商品加载失败需可重试，不能将“未能验证”和“已确认无权益”混为一谈。

本机可保留经过验证的交易材料与最后有效状态用于暂时离线，不能用普通 UserDefaults 的 isPro 当信任来源。已有有效购买在临时网络失败时继续使用；完成权威状态刷新或收到已验证撤销时更新授权，不无限保留已退款权益。新设备从未取得有效交易时，需要连接 Apple 恢复，不能宣称永久无需联网。

无后台方案不保证完全防改系统时间／设备重置／破解。试用时钟结合交易起点、同次启动单调时钟和本机已见最大时间；发现明显倒退时要求联网核实，不悄悄开启新 7 天，也不影响已经验证的永久购买。严格跨设备防滥用是另一个成本等级，首版不为此引入自建授权服务。不要把 DeviceCheck 在其他平台的示例直接当成 Mac 可用方案。

Family Sharing 是否开启单独决定并验证，暂不宣传家庭共享。Mac 买断不自动等同于未来 iPhone 应用或其他商店渠道购买。

## 4. 更新和永久权益

商店版本的程序更新完全由 Mac App Store 分发，不加入 Sparkle、更新下载服务器或自修改可执行文件。帮助入口“在 App Store 中查看”使用正式应用链接；应用内可显示本地版本与随安装包附带的更新说明。

试用到期不禁止商店下载更新，但更新不重置试用；永久购买随账号恢复，更新和资料库迁移不能要求重新付费。格式升级保持原子迁移与错误保护，旧版本不能误写新格式。

用户所说“永久更新”的推荐准确表达：一次购买，永久解锁；本应用后续发布的更新免费。不设置按大版本重复解锁的暗门。它不保证无限年限发布新版本或永远兼容所有系统；未来第三方 API 费用不在买断承诺内。现有按需下载本地模型能力仍遵守此前包含在买断内的路线。

## 5. 是否需要网络服务

| 环节 | 首版是否需要自己的动态后台 | 网络依赖 |
| --- | --- | --- |
| 本地记录、整理、导入导出 | 否 | 核心操作离线 |
| 领取试用、购买、恢复、权益刷新 | 否，使用设备端 StoreKit 验证 | Apple 商店服务 |
| 程序下载和更新 | 否 | Mac App Store |
| iCloud Drive 同步（另行实现） | 否 | Apple iCloud 与用户账号／空间 |
| 隐私政策、支持页、说明 | 否，静态网站即可 | 访问网站需要网络 |
| 本地模型按需下载 | 不需要推理后台，但需要可靠文件分发地址 | 可用对象存储／CDN 或许可允许的分发渠道；有带宽成本 |
| 用户自配远程模型 | 通常不需要 Foldpin 后台 | 用户所选服务，凭据由用户提供 |
| 未来官方云 AI／账号／跨商店授权 | 届时评估，通常需要 | 不纳入当前首版 |

“无需自己的后台”不等于整个生命周期完全无网络。模型下载只下载合法模型数据，代码随商店应用分发；模型许可、下载完整性和审核要求在 AI 专项核对。App Store 沙盒内启动用户任意外部 Agent 也须独立可行性验证，不能因商业路线成立就保证所有 Agent 集成都能上架。

## 6. 上架与验证

准备 App Store Connect 应用和两个 IAP 商品、本地化、价格、购买截图、隐私政策和支持 URL、审核说明、税务／银行及付费协议。私测使用 StoreKit 配置测试＋Sandbox＋TestFlight；测试交易不授予生产购买权益，提交说明需让审核员能验证试用和到期状态。

验收至少覆盖：

1. 首次领取、购买取消、pending、成功、验证失败与重试。
2. 7 天边界、时区变化、重装、换 Mac、时钟回拨，不重置已领取试用。
3. 永久购买恢复、更新后权益、试用期间直接购买。
4. 退款／撤销、账号变化、离线与服务失败，区分未知和已确认失效。
5. 到期时中文 IME、录音、附件导入及待保存内容不丢失，仍可查看导出。
6. 所有新建／编辑入口一致限制，查询与导出不被误锁。
7. 商店更新、数据升级失败及不兼容系统不破坏原资料库。
8. 签名沙盒下目录授权、登录启动、全局快捷键与音视频行为。

真实时间边界用注入时钟测试，不让生产界面包含随意重置试用按钮。沙盒证据不等于生产商店行为全部已验收。价格、商品 ID 和正式网址在用户确定后补齐，不阻塞本地 StoreKit 状态机开发。
