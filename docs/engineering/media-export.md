# 媒体导出 · 2026-09-09

图片右上「更多」、右键和六点区块菜单提供「导出图片…」。音频播放条「更多」及区块菜单提供「导出音频…」。统一使用系统保存面板选择位置，文件已经存在时由系统确认替换。视频随后接入，同样从播放块更多 / 右键 / 六点菜单进入「导出视频…」，沿用原始文件导出流程。

图片读取 `assets/<UUID>.original`，ImageIO 检查实际格式并生成对应后缀，逐字节导出原始文件。尺寸和标题只是笔记元数据，不烘焙到导出文件；不缩小、不转码，原始动图帧也随文件保留。原图缺失或无法识别时提示错误，不静默改用低分辨率 PNG 预览。

音频保留导入文件或录音的现有格式。正在录制或未完成的草稿先完成并保存，失败保留资产与错误状态，不继续导出；普通播放无需暂停。开始导出前绑定具体区块 UUID，生成不可变源文件描述，后续切换选区或纸片不会导出其他块。

`Editor/MediaExport.swift` 共用文件名处理、NSSavePanel、后台原子写入与错误提示。取消保存面板不写目标文件；成功导出不删除或修改原始资产、不修改已完成块的正文或撤销栈。文件名移除路径分隔符和控制字符，避免重复媒体后缀。沿用已有 user-selected read-write 沙盒权限，不增加网络、磁盘全盘访问或媒体设备权限。

验证使用合成 JPEG、临时音频字节和不可见编辑器，覆盖原图格式检测 / 原始字节与尺寸、音频字节不变、文件名、草稿拒绝、原文件消失时保留已有目标文件、菜单 UUID 与选区不变。系统保存面板的真实交互和沙盒授权后的实机导出仍需从当前 Xcode 运行新版检查；未打开用户纸片或录制声音。
