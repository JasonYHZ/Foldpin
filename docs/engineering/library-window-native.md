## 设计依据与本轮实现

重新阅读 `docs/design/library-window-v0.1/README.md` 的 v0.7–v0.10、`implementation-spec.md` 和原型 HTML／CSS／交互脚本，并对照 `09-macos-layout.png`。初期“没有分类侧栏”的探索已经被后期 macOS 布局替代。

- 普通可复用 NSWindow，使用系统红黄绿、原生 unified 工具栏。工具栏放侧栏开关、当前位置、网格／列表、搜索、新建。⌘F 在浏览时进入库内搜索，正在编辑时沿用正文查找。
- 左侧原生 sidebar List：所有纸片、桌面上、已收纳、收藏、最近删除，以及可折叠集合。显示全库状态数量，集合显示未删除成员数。
- 中间默认彩色纸片网格，可切换列表。状态标记、图标、有限摘要、修改日期、收藏标记；单击预览，双击打开／定位。类型筛选、字面搜索与排序真实作用于当前导航。
- 右侧约 340 点预览，纸片颜色、图标、首行标题与正文；底部主操作、编辑、更多。可关闭预览；窄窗口先折叠侧栏，再显示完整详情，关闭详情回到原查询。
- 侧栏改由 NSSplitViewController 的 sidebar 行为提供系统悬浮液态玻璃，保留系统圆角、内缩、安全区域及辅助功能材质回退；移除整窗 EditorGlassSurface 和侧栏额外底色。中间内容面与彩色纸片保留阅读底色。
- 已收纳编辑继续借用原有 NoteEditingSession；桌面只读并定位，最近删除只读并恢复。切换前完成输入和媒体保存，失败保留编辑。

## 管理与数据

`NoteDocument` 增加可选兼容的 `isFavorite` 与 `createdAt`。旧文件收藏缺省 false，创建时间回退已有 modifiedAt；新建和副本记录独立创建时间。收藏不改正文修改时间，保存失败回滚元数据。

集合使用 `NoteCollections` 保存独立版本化 `collections.json`，支持创建、重命名、加入／移出多个集合、删除集合；不包含正文或媒体。原子保存成功才更新内存，损坏禁写并可重试；空名／重名不合并。删除集合不删除纸片。成员 UUID 在纸片软删除后保留。

最近删除的恢复通过一次原子保存回到已收纳状态，不自动弹出桌面。多选支持打开、收纳、收藏、加入集合与软删除／恢复；选择范围在导航／筛选／搜索变化时清空。集合整体打开／收纳忽略当前查询，排除已删除成员。批量结果显示成功与失败数，不冒充跨文件原子事务。
