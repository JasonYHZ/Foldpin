# 纸片导出：Markdown / HTML

2026-09-14 按用户要求加入。单张桌面纸片的「操作 → 导出…」、收纳右侧单选操作、卡片右键和多选「更多 → 导出…」均可进入同一个原生保存面板。格式在面板底部选择 Markdown 或 HTML。

## 输出规则

- 单张无资源纸片输出 `.md` 或 `.html`。
- 单张包含图片、音频、视频或普通附件时输出 ZIP；正文与 `assets/` 一起打包，使用相对路径，解压后可移动整个目录。
- 多选统一输出一个 ZIP，每张纸片各占「序号-标题」目录，包含独立正文与资源。序号避免同名纸片覆盖，资源 UUID 避免同名附件冲突；文件名按 UTF-8 长度截短，保留常见扩展名。每张按当前库顺序输出。
- 图片同时保留原始文件与 PNG 显示预览。正文引用 PNG 并提供原图链接；音视频和普通附件保留实际文件字节。
- HTML 带独立样式，不依赖在线字体或脚本；音视频使用原生浏览器播放器及下载链接，具体编解码支持由浏览器决定。Markdown 通过相对链接引用音视频 / 附件。

## 内容保真

支持 H1–H4、段落、引用、项目 / 有序列表、待办状态、分隔线、代码语言、表格和已有行内格式。代码围栏会避开正文内的反引号。HTML 转义用户文字并限制脚本 / 远程资源；图片外链仍作为用户主动点击的链接。

Markdown 常见独立行内格式输出标准标记；重叠格式或跨行格式回退内嵌 HTML，避免相邻分隔符产生歧义。有标题行且无标题列的表格使用 Markdown 表格；其他表格使用 HTML，避免凭空把首行当标题。

## 事务与编辑状态

先提交选中纸片的组合输入 / 图片标题并完成录音、保存，再取得文档快照。只对已有控制器准备编辑状态；从未打开的已收纳纸片直接读取 NoteStore，不为批量导出创建一批 NSTextView。导出不切换侧栏、收纳状态、纸片位置或撤销历史。

正在导入、未完成媒体草稿、远程图片占位或缺失本地资源会阻止导出，不能静默省略。保存面板取消不创建文件；导出阶段有进度和取消入口。正文构建和资源打包在后台完成，写入替换临时目录，成功后才原子替换用户选定的目标。失败 / 取消保留已有导出；不能选择资源原件本身作为导出目标。

`NoteZip` 实现 ZIP64 的 stored 条目，按 1 MiB 分块读取媒体并计算 CRC32，支持 64 位尺寸与偏移；不把整段视频读进内存，也不对已经编码的媒体再次压缩。ZIP 格式依据 [PKWARE APPNOTE](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)。不新增系统命令执行、联网、后台监听或文件清理功能。

## 实现入口

- `Core/NoteExport.swift`：文档快照、格式转换、资源路径与原子写入。
- `Core/NoteZip.swift`：原生 ZIP64 写入。
- `Editor/NoteExportPresenter.swift`：格式选择、保存面板、进度与错误。
- `NoteAction.exportNote` / `PaperWindowController.exportSource`：桌面操作与共享编辑器准备。
- `ShelfPreviewWindow.exportSources` / `exportNotes`：单选、多选与右键菜单，目标固定为触发时的 UUID 集合。
