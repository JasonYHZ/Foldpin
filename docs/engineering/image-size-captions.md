# 图片缩放与标题 · 2026-09-09

用户提供 Notion 截图，要求悬停缩放手柄与图片下方标题。本轮沿用原生图片附件、六点块菜单和现有撤销机制。

## 交互

- 鼠标进入图片后出现左右竖形手柄，以及右上方「编辑标题 / 恢复尺寸 / 更多」工具条。拖动左右手柄保持图片居中和原始宽高比，窗口内不溢出正文；小图空间不足时隐藏工具条，六点 / 右键菜单仍有全部入口。
- 用户追加要求：右上三个操作共用一个 98 × 36 点圆角底板，按钮悬停单独高亮。停留 350 ms 后在按钮上方显示深色文字提示；屏幕上方不足时移到下方。提示不抢焦点、不接收鼠标，移出、点击、工具条隐藏或位置改变时清理。
- 拖动只预览显示，松开后一次结构变更、一次原生撤销；Esc 或失焦取消拖动。图片移动排序仍使用已有六点手柄。
- 点击标题工具按钮或区块菜单「编辑图片标题」，在图片下方原位输入。Enter / Tab 或结束编辑确认，Esc 取消，中文组合输入优先交给系统。标题为可选单行，空值显示占位，菜单可移除标题。标题显示使用次级墨色，长标题省略；编辑框可水平移动光标。
- 收纳、折叠、退出等控制器提交路径先完成标题编辑，再沿用 NoteStore 保存保护。原图文件不因标题和尺寸变更重写。

## 数据与渲染

`NoteImage.displayWidth` 是可选显示宽度（点），`caption` 是可选标题；旧 JSON 缺省 nil，仍用 v2 / content schema 1。标题属于图片区块元数据，移动、复制、创建副本与撤销均随图片保留。显示宽度合法范围为 40–10000 点；实际布局限制在正文宽度内，并保留既有 600 点最大显示高度，始终按原始比例缩放。窄纸片临时压缩显示，不覆盖偏好宽度，扩大后可恢复。

`ImageBlockLayout` 统一图片、标题高度和等比布局。`BlockTextCodec` 用居中段落放置一个附件，标题和图片同属这个附件；真实 PNG / original 文件保持独立。`PaperTextView.imageFrame` 使用 TextKit 的 `frameForTextAttachment` 定位实际区域，而不是将整个块的行宽当成图片宽度。

每个编辑器只保留一个 `ImageBlockControls`，位于 NSScrollView 上层；除可见的按钮、手柄和活动标题输入框外 hitTest 穿透。悬停、滚动、布局变化合并定位。标题编辑使用一个按需显示的 NSTextField，未提交草稿不改正文；拖动预览只替换显示 attachment，不改元数据、不写盘、不生成逐帧撤销，提交前恢复原始显示，再走现有 replaceDocument。

整张复制时，纯文本和 HTML 保留标题，HTML 用 figure / figcaption；RTFD 将原 PNG 作为附件，标题作为可选文字插入，避免把标题烘焙进图片。Foldpin JSON 保留尺寸与标题，单独「复制图片」仍只输出原图像素。读取 / 保存验证新增元数据，未更改已有资产缺失保护。
