# Markdown 远程图片导入

2026-09-11：普通 Markdown 粘贴支持 HTTP / HTTPS 图片，保存为本地资产；包括链接包裹的图片和静态 SVG 徽章。

## 使用范围

- `![名称](https://example.com/image.png)` 转成原生图片块；`![名称](链接地址)` 同时保留图片和外层链接。空 alt、中文、引用式图片地址也支持。
- 图片仍使用现有居中图片块、缩放手柄、标题与更多菜单。多个徽章逐个成块，尚无段内徽章横排布局。
- 双击图片正文或使用「打开图片链接」访问外层地址。HTTP / HTTPS / mailto 可打开；`LICENSE` 等相对链接保留原值并禁用打开，不猜测仓库基址。
- 保存占位后自动下载每次粘贴的前 32 张图片，同一编辑器最多同时 3 个请求。其余占位可以点击加载。下载失败显示「图片加载失败 · 点击重试」，菜单提供重新加载和还原图片 Markdown。
- 再次打开纸片不自动发起下载，保留占位供手动重试。已下载图片使用本地预览，不会每次打开访问来源。
- 代码、表格单元格与「粘贴为纯文本」仍保持字面内容。转义破损的 Markdown、不支持的图片协议与 HTML 不自动修复或执行。不会回头改写已有纸片里的字面文本。

## 数据与下载

`NoteImage` 新增可选 remoteSource / remoteState / sourceMarkdown / link / isSVG 字段，沿用 JSON v2 / content schema 1；旧图片无需迁移。只有有效远程占位允许在没有本地文件时保存。成功导入后清除占位状态，恢复原有原图与预览文件检查。源 Markdown 是保留语义的规范化图片片段，不保证逐字节等同原始格式。

`RemoteImageImporter` 使用临时 URLSession，不共享 cookies、凭据或磁盘缓存。仅下载图片地址，外层链接由用户主动打开。单次响应最多 20 MB，检查 HTTP 状态、声明长度和实际字节数；请求 / 资源超时为 20 / 40 秒，跳转限 HTTP / HTTPS 且不允许 HTTPS 降级到 HTTP。工程增加应用沙盒的 outgoing network entitlement。

栅格图复用 NoteImageImporter 的后台校验 / 预览生成和原图保存。SVG 限 2 MB、10,000 元素、深度小于 64、单边不超过 10,000、面积不超过 16 MP；先校验 XML 和静态元素，拒绝脚本、样式、外部资源、实体与递归 use。原生 NSImage 生成最多 1400 像素的 PNG 预览，保留原始 SVG 供导出。适用于常见静态徽章，不承诺完整浏览器 SVG 标准。显示宽度按 SVG 原始尺寸设置，避免徽章放大到纸片宽度。

## 编辑保护

下载任务绑定块 UUID、占位图片 UUID 和来源；删除、撤销或改变来源后过期任务不能恢复旧块。输入法组合、活动单元格组合、图片标题编辑和缩放期间延后提交。完成后读取当前文档，只替换匹配图片，通过原生结构撤销路径提交，保留周围新编辑、选区与滚动位置，并沿用 NoteStore 保存错误提示。

占位先保存，保存失败不自动下载。失败不删除源信息，原生菜单可恢复可编辑的 Markdown 文本。已下载资产不清理，以供撤销。任务有独立身份，取消的旧任务不能清掉同块新重试。

复制整张纸片时，未加载图片以 Markdown 进入便携文本 / HTML / RTFD，Foldpin JSON 保留占位。已加载图片仍携带 PNG；HTML / RTFD 保留合法外层链接。SVG 导出保留原始 SVG，复制图片使用 PNG / TIFF。

## 验证边界

Debug 构建通过并核对签名含 network.client。216 项完整回归通过；随后引用式 / 多行图片补充与 Markdown 相关 12 项检查通过。使用临时笔记、合成 SVG、独立命名剪贴板和 URLProtocol 模拟响应检查解析、下载、失败、尺寸限制、资产保存、导出、复制链接、撤销与过期任务。不读写真实纸片，不访问系统通用剪贴板。真实网站连通性、登录保护图片、桌面双击与悬停菜单仍需运行新版验收。
