# 自定义快捷键 · 2026-09-09

## 设置与范围

设置新增独立「快捷键」页，在「窗口内 / 全局」切换。每行显示功能及当前组合，点击录入框后按组合键；Esc 取消、Delete 清除，另有清除按钮、单项恢复默认和本页恢复默认。修改立即生效，中英文共用同一配置；不改笔记正文、不重建编辑器、不影响撤销栈。

窗口内按应用操作 / 当前纸片 / 当前编辑器分组。应用操作包含新建、收纳、排列 / 撤销排列、收起全部；纸片操作包含操作菜单、置顶、折叠、图标 / 颜色、复制全部、创建副本和六种选色；编辑器包含录音、图片 / 音频 / 视频导入、块菜单、创建区块副本、上下移动。纸片操作仅作用于获得焦点的纸片；编辑操作要求正文可编辑、无 IME 组合、未进入表格单元格或图片标题编辑。复制、粘贴、撤销、关闭、退出、标准文字格式仍使用系统组合。回车、Tab、斜杠等输入规则不开放改绑。

全局仅开放四项：新建纸片、快速录音（开始 / 完成）、显示 / 收起纸片、打开收纳。Foldpin 必须保持运行。用户确认四项默认分别为 ⌃⌥N、⌃⌥R、⌃⌥Space、⌃⌥O。已有自定义与显式清除保留；旧 `captureShortcut = 1` 的 ⌃⌥N 收起组合迁移为覆盖值，新建暂不占用该组合。引入默认值时，如组合已被其他自定义动作占用，对应新增全局项保持未设置。`globalShortcutDefaults.v1` 标记一次性迁移，整页恢复默认使用新的四组组合，不再重新读取旧选择。局部和全局可分别为相同功能设置不同组合，但组合不得重复占用。

首版支持 Command 或 Control 配合字母、数字、标点、Space 和方向键，可加 Option / Shift；纯单键、单独 Option / Shift、修饰键、系统导航键和多段组合不支持。按物理键码与四个修饰键保存，字母标签按标准 ANSI 键位显示；其他实体键盘布局尚未实机验证。

## 路由与冲突保护

`Core/ShortcutBinding` 定义组合与动作 ID；`ShortcutSettings` 管理版本化应用偏好 `customShortcuts.v1`，未改绑项沿用既有 `NoteAction` 默认值。显式清除和恢复默认是不同状态。普通文字复制等系统动作保留；通过 Carbon `CopySymbolicHotKeys` 检查已启用系统组合，并检查全应用跨作用域的重复设置。其他应用的占用无法完整枚举，以全局注册结果为准。

`GlobalShortcut` 同时管理四项 Carbon 注册。提交时先注册新组合，成功后才释放已不需要的组合；失败只清理本次新注册，保持旧配置和注册。重用已持有组合允许整体配置交换，无需先注销所有按键。记录按下 / 松开，忽略按住的重复事件；注册时若物理键仍按下，等待释放后才允许触发新动作。

`ShortcutRecorder` 只在主动录入时安装本地事件监控，结束、切换焦点、移出窗口、窗口失焦时清理。不增加全量全局键盘监控，不要求辅助功能或输入监控权限。录入既有全局组合时，Carbon 回调把组合交给录入框而不执行动作，正常注册保持存在。应用内路由在录入期间停用。

菜单、SwiftUI 应用命令、⌘K 动作面板、颜色菜单、标题栏 / 底栏的提示从当前配置读取；旧固定 ⌘M 和编辑器块移动 / 创建副本路由已移除。标准 ⌘W 仍按原保存 / 收纳流程处理，不可改绑。设置页、纸片工具提示观察配置，正文不观察配置以避免全文刷新。区块菜单在打开时构造，使用明确 UUID 及当前快捷键。

## 快速录音

`QuickRecordingFlow` 串行化权限和窗口创建。在没有活动录音时，先请求麦克风权限，允许后才创建并保存新纸片、显示窗口、等待编辑器布局，再通过既有录音流程保存草稿并开始采集。权限拒绝不新建纸片；连续触发不同时创建多张或重复申请权限。窗口内「录音」继续插入当前纸片。

已有录音（包括暂停中的录音）时，全局组合唤出该纸片并完成 / 保存，不再新建。保存失败保留文件和错误，记住失败目标，下一次触发先重试保存；未成功前不以新纸片替代失败录音。完成 / 保存沿用现有 NoteStore 与原生撤销，不增加全局停止监听或录音设备权限。

## 验证边界

定向检查使用独立 UserDefaults 测试域、不可见原生窗口、模拟 Carbon 注册边界以及假的麦克风授权结果，覆盖默认迁移、重新读取、清除 / 恢复、跨作用域重复、系统保留、注册失败回滚、旧组合失效、录入取消 / 捕获、改绑后区块原生撤销、按住去重，以及拒绝授权 / 重复触发 / 保存失败不新建。

Debug 原生构建通过；8 项定向检查通过。窗口内 / 全局设置页已用不可见原生宿主检查英文布局，32 个新增文案键已核对两套打包资源完整；中文真实窗口、滚动与辅助功能仍需实机确认。

本轮不注册测试用真实全局快捷键，不唤起用户纸片或启用麦克风。真实跨应用按键、首次权限面板、快速录音设备链路、不同键盘布局和 VoiceOver 仍须当前 Xcode 运行新版后验收。核心路由和合成结果不能代替这些实机场景。
