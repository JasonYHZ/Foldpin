# 纸片颜色

2026-09-09，实现 FP-013 的逐张纸片配色。

## 使用

右键或 Control-click 点击纸片标题栏空白处，选择颜色。也可先激活一张纸片，再打开屏幕顶部 Foldpin 图标 →「纸片颜色」。菜单提供色点、名称和当前选中的勾号，中英双语；原色、黄、绿、蓝、粉、紫共六项。折叠状态同样可选色。标题栏仍只有关闭、置顶、折叠和收纳操作；正常左键拖动不变。

颜色属于单张纸片；设置中的纸感 / 通透与跟随系统 / 明亮 / 暗色仍是应用级偏好。

## 表现与保存

- 纸感：日间柔和浅色纸张，夜间降低亮度并保留色相，文字保持深色墨迹。原生底层与 SwiftUI 填充共用同一配色，活动表格单元格同步，细边与阴影保留。
- 通透：同一个原生 NSGlassEffectView 使用低强度 tintColor，保留 regular 材质与阅读底色。原色为无染色。减少透明度 / 增强对比度时，原生与 SwiftUI 均使用对应的实色背景。
- 原有代码主题及代码背景透明度不变，不强制覆盖应用明暗主题，不新增纹理、动画、网页渲染或逐帧任务。
- `NoteDocument.color` 是 JSON v2 的可选展示字段；旧 v1 / v2 和未知预设回退 original，读取不改写文件。正文 content、ID、modifiedAt 和窗口几何不因换色变化。
- 按原有 450 ms 合并保存，收纳 / 退出前仍 flush；保存失败保留内存选择并显示错误，可重试；读取失败不允许选色写入。
- 菜单绑定具体窗口；原生表面只订阅去重后的颜色值，不响应每次文本或几何发布。换色不重建 hosting view / NSTextView、替换正文或重跑高亮，仅重新绘制背景和活动单元格底色。
