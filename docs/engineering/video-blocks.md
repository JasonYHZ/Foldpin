# 本地视频区块 · 2026-09-09

## 交互与范围

正文 `/` 媒体组选择「视频」，或原生插入菜单「导入视频…」，也可粘贴 / 拖入本地视频文件。首版支持系统可解码的 MP4、MOV、M4V，单个文件不超过 1 GB。文件扩展名正确不等于编码可播放：导入会检查视频轨道、时长、尺寸、播放能力并实际解码一帧；失败提示错误，不插入空块。

视频以封面和居中播放按钮显示，下方是文件名、时长及「更多」。点击播放才创建 AVPlayer，使用 AVPlayerView 原生进度与音量控件，保持比例，竖屏按方向变换显示。高度随正文宽度调整，画面区域限制在 120–400 点，名称栏 32 点；不自动播放、不裁剪视频。菜单提供「导出视频…」、复制区块、创建副本、上下移动、删除；六点手柄继续支持块排序。暂不支持视频录制、网址嵌入、转码、剪辑、手动尺寸与标题、独立全屏或画中画。

播放视频会暂停现有音频 / 视频；开始音频播放或录音也暂停视频。录音过程中拒绝视频播放，避免混入录音。失焦不会暂停已播放的视频；滚出编辑视口、折叠、收纳、删除或退出时暂停并释放解码资源，保留会话中的播放位置，再次点击可继续；播放位置不写入笔记，不产生撤销记录。

## 存储与实现

`NoteVideo` 保存资产 UUID、名称、受限的扩展名、时长及变换后的画面宽高，`NoteBlock.video` 为可选元数据。旧笔记仍可读取，沿用 JSON v2 / content schema 1。视频块必须含有效元数据，不能附带正文或文字标记。文件路径只由 UUID 和允许的扩展名生成，文件名不参与路径拼接。

`NoteVideoImporter` 在后台复制到本地 `assets/<UUID>.<ext>`，验证后生成最大边 960 像素的可选 `.poster.jpg`。不改源文件、不转码、不跟随容器外的媒体引用；导入失败或源区块快照失效时清理本次未插入资产。导入期间不改正文，结果通过 `insertVideo` 绑定源块快照，保留行中斜杠前后文字与原生撤销。插入后同步尝试保存；保存失败保留原始文件与编辑内容，显示错误。

`VideoTextAttachment` 占一个 UTF-16 附件字符；`PaperTextView` 按 TextKit 附件 frame 放置 `VideoBlockView`，只创建可见播放器视图，模型保留轻量会话状态。结构变更沿用 BlockTextCodec 元数据与同一原生 UndoManager；移出视口释放播放器而不销毁正文编辑器 / 撤销栈。已插入的资产删除时保留，供撤销、创建副本、最近删除恢复使用；NoteFile 保存检查视频文件存在，缺失时不覆盖旧 JSON。

导出走现有 `MediaExport` 系统保存面板，原子写入原始文件字节。结构复制与整张复制保留视频，RTFD 包含实际文件附件，HTML 使用内嵌 video 数据；接收应用能否播放取决于它对格式的支持。音频和视频的富文本复制合计限制 32 MB，超限提示导出；先生成完整数据，失败不替换剪贴板。Foldpin 粘贴只解析本地 UUID 引用，不读取剪贴板里的任意外部资产路径。

## 验证边界

必要检查使用临时生成的无声 H.264 MOV、带旋转变换的视频、不可见原生窗口与专用测试剪贴板，不打开用户纸片或录制声音。真实指针操作原生进度 / 音量控件、长视频资源占用、不同编码与 VoiceOver 仍待当前 Xcode 运行新版验收。

最终 6 项视频定向检查通过：原始字节 / 方向 / 封面 / 导出、无效文件与元数据、持久化与缺文件保护、实际播放按钮和播放时间推进 / 原生撤销 / 删除 / 解码资源释放、富文本复制 / 超限与失败保留剪贴板、整张纸片删除后重新读取与恢复。此前包含斜杠菜单及行中插入的 18 项相关检查通过。Debug 构建成功，中英文打包资源已核对。合成封面做了离屏检查；这不替代真实桌面合成、纸面颜色或鼠标操作验收。
