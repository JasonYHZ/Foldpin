# 非 AI 功能实现记录

日期：2026-09-15。真实仓库 main 开发；没有新建分支、提交或发布。对应[开发方案](non-ai-release-readiness-plan.md)。

## 入口与行为

- **设置 → 通用**：登录启动、使用说明、反馈，以及应用版本／构建号。设置保留外观、快捷键、数据与存储页和原快捷键页跳转。
- **首次启动**：新安装在主动启动、默认库正常可写且没有已有内容时，直接保存并打开一张普通可编辑的使用说明纸片。没有欢迎窗口、跳过按钮或其他引导步骤。说明压缩为记录、添加内容、贴放、收纳和更多操作五条，保留一个可勾选待办及新建／操作两项快捷键。
- **帮助／设置 → 使用说明**：重新打开同一纸片，保留编辑、位置和大小；已软删除时定位最近删除，永久删除后仅明确打开帮助才创建新 UUID。自动创建只发生一次，收纳或删除后不会在后续启动补回。创建通过正式保存路径，成功后才标记完成；固定 UUID 支持失败重试。正文按创建时语言及实际快捷键生成，后续设置变化不覆盖用户内容。
- 打开资料库前判断首次使用证据；已有库、书签恢复、只剩删除记录、主动空库和登录后台启动均不自动插入说明纸片。新安装不额外生成空白纸片。
- **登录时启动**：使用 SMAppService.mainApp 的实际状态，区分已开启、待批准、未注册、未找到和失败。仅用户操作时注册或注销；系统设置关闭后只刷新状态。仅对系统 Applications 目录内运行的应用开放注册，开发构建不静默安装自己。
- **帮助 → 反馈**：可编辑、可预览、可复制的反馈模板。诊断只含版本、构建号、系统版本和处理器架构；没有纸片内容、目录、用户名、遥测或自动发送。反馈地址尚未确定，未编造邮箱／网页入口。
- **文件 → 导入 Markdown…／收纳右上新建菜单 → 导入 Markdown…**：选择文件，选择复制附件目录或保留链接，再在结果窗口开始导入。每文件一张已收纳纸片；单文件成功后选中编辑，批量不弹出大量桌面纸片。结果保留文件名、状态和降级原因，可重试未成功项目。
- **设置 → 数据与存储 → 扫描用量**：统计当前正文／集合、历史修订、媒体、普通附件、恢复文件和其他文件；本机必要数据单列。较大附件列出关联纸片、历史／最近删除标记，可定位纸片或在访达中显示资源。展示扫描时间，未知／未下载数据明确标为不完整，不按零占用宣称完整。

用户明确暂缓应用更新、发行渠道和 AI 授权。本轮没有新增更新检查、自动安装、收费／试用限制、AI 权限、签名上传或公证操作。

## Markdown 导入支持矩阵

| 内容 | 本轮行为 |
| --- | --- |
| UTF-8／带 BOM UTF-8、UTF-16 | 严格解码；未知编码或超限报错，不有损转码 |
| 普通文字、H1–H4、列表、待办、引用、代码、常用行内格式、基础表格 | 复用原生 MarkdownPasteParser，不创建第二套编辑器 |
| YAML front matter、HTML、嵌套或其他不支持结构 | 保留源码，结果说明格式降级；不执行 HTML／脚本 |
| 单独成行的 `![说明](图片路径)` | 授权根目录内的本地图片复制原件并生成预览；说明作为标题 |
| 单独成行的 `[说明](文件路径)` | 授权根目录内普通文件复制为附件；音视频亦保留为文件附件，不在导入时解码为播放器 |
| 行内图片／文件链接、引用式资源、复杂链接语法 | 保留源码／链接，不静默删除；首版不保证复杂 Markdown 无损往返 |
| 远程图片 | 保留原始链接，不建立待下载占位，不联网 |
| 缺失／超限／未经授权资源 | 保留原始链接并提示；可选择跳过包含未解析内容的整张文件 |

单文件 5 MiB、每批最多 50 文件、正文总量 25 MiB、原资源复制总量 512 MiB。受现有图像解码的尺寸与格式限制。源 Markdown 与附件不改写；拒绝目录穿越、越权绝对路径与资源路径中的符号链接。

后台准备资源到本任务临时目录，验证后晋升 UUID 资源，再沿用 NoteLibrary／NoteFile 原子保存。未提交的失败／取消只清理本任务已知临时文件；保存结果存在歧义时保留资产，不能以清理为由破坏可能已提交的纸片。导入保存错误单独显示，不污染整库读取状态。每项 UUID 在当前导入会话稳定，重试已提交项目不覆盖后续编辑；新一次明确导入允许创建副本。

LibraryFileActivity.imports 覆盖整批任务，切库／迁移和退出须先完成或取消；外部刷新不得在任务中安装过期快照。提交前检查库对象、路径和切换代次。没有批量正文撤销，成功纸片可使用现有最近删除流程。

## 只读统计与资源清理边界

LibraryUsage 独立遍历文件元数据，读取本机可用的笔记／修订以建立全部已保留历史引用，不调用会合并冲突的默认 LibraryDisk.snapshot，也不请求 iCloud 下载。按父关系将当前头部与历史修订互斥分类，附件按物理文件只计一次。已升级旧库的保护标记被识别为恢复材料；缺父修订、基线、未知／损坏记录、未下载文件都使结果不完整。扫描后重新核对文件集合／大小／修改日期，库代次和已安装修订变化时弃用旧结果。

`FoldpinLocalState` 的书签、目录锁、迁移日志和桌面状态属于必要数据，没有被标成缓存。

**N6 尚未开放。** 当前共享库保留不可变历史与删除记录；本地路径也不能证明未共享，原剪贴板结构引用没有持久资源租约，缓存会话仍保留撤销。因此磁盘扫描无引用不等于安全可删。界面明确显示限制，没有删除按钮、自动清扫、隔离区或历史压缩。本轮只清理新增导入任务自己产生且确定未提交的暂存内容，不清理用户库的既有资源。
