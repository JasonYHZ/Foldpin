# 纸片内查找与替换 · 2026-09-10

当前纸片支持文字查找、区分大小写、上一个 / 下一个匹配、替换当前匹配和全部替换。默认快捷键为 ⌘F、⌘⌥F、⌘G、⌘⇧G，设置 → 快捷键 → 当前编辑器可改绑；顶部「查找」菜单也提供入口。路由绑定获得焦点的纸片，查找框或表格内按键仍交给当前纸片，不操作后台窗口。已有自定义占用组合时，新查找动作保持未设置，不抢占。

## 搜索范围与交互

匹配正文（含标题、列表、待办、引用）、代码、表格单元格和图片标题。不跨区块 / 单元格拼接匹配，不查找自动生成的列表编号、资源路径、媒体文件名、图片像素或音视频里的内容；不包含 OCR 或转写。默认忽略大小写，使用字面匹配，无正则表达式。

查找条使用原生 NSSearchField / NSTextField，通过当前 NSScrollView 的 findBarContainer 展示。2026-09-10 按用户图片改成单个 17 点圆角面板，上行依次为展开箭头、无边框查找框、Aa、匹配数量、前后箭头及关闭；下行分隔后为替换框和两个带悬停提示的图标按钮。单行高 54 点、展开高 92 点，错误 / 超限另加 36 点可见提示；大小写、只读及组合输入保护保持。配色跟随原生明暗主题。随后按用户要求，圆角面板接入共享 EditorGlassSurface 的 regular 液态玻璃；不再绘制覆盖材质的实色填充。查询和替换草稿只保留在该纸片会话中，不写偏好、笔记或系统查找剪贴板。输入组合期间不改写查询或正文，回车查找下一个、Shift+回车上一个，Esc 先关闭查找。关闭 / 折叠 / 收纳前清理结果与排队工作，不抢回焦点。

普通匹配使用浅黄色，当前匹配使用橙色与描边。高亮是显示层，不改 NSTextStorage 字符属性、代码高亮、复制结果或原生撤销。导航滚动到匹配，保留原文字选区及查询框焦点。附加文字根据实际表格附件、图片标题位置绘制。

## 替换与保存

`Core/NoteSearch` 使用 UTF-16 范围和块 UUID / 字段标识定位。单次替换与全部替换先对原内容快照计算结果；提交前重新核对版本、正文、只读和组合输入状态，过期工作不能覆盖新输入。空替换允许删除匹配；替换文字中的换行转成同块行分隔符，不能凭替换产生新结构块。图片标题仍遵守既有 4,096 字符限制，超限提示并保留原文。

保留区块 UUID、类型、媒体资产、表格结构和其他元数据，匹配外的行内格式保持，替换文字继承匹配首字符的行内标记。通过原有 replaceDocument 一次提交 / 原生撤销，使用已有保存及错误保护；不循环调用逐项编辑，不重新创建窗口或编辑器。替换完成后查询框内的 ⌘Z / ⌘⇧Z 路由到纸片撤销；再次编辑查询或替换草稿后恢复原生字段撤销。

## 性能

- 只在查找条开启时响应内容变化。140 ms 合并连续查询，延迟后才取不可变值快照，后台扫描；新查询 / 正文变化 / 关闭取消过期计算。
- 查询没有磁盘、媒体解码、语法解析或全文属性刷新。扫描结果发布一次，使用块索引分组；绘制只取当前 TextKit 视口，长块用二分定位可见匹配。
- 表格及图片标题仅为可见字段构造文字布局，最多缓存 64 项，查询 / 内容改变即失效，尺寸变化重建对应缓存。
- 替换按字段一次构建字符串，格式位置用二分查找映射，避免匹配数乘以格式数的遍历。后台结果通过既有原生结构提交，提交仍有一次全文渲染成本。
- 最多保留 50,000 个匹配。超过时明确提示缩小范围，禁用全部替换，防止只替换截断结果却声称完成全部。

## 验证

Debug 构建通过，4 项搜索检查及 4 项快捷键回归通过，两套打包语言资源包含全部新增文案。定向测试覆盖中文 / Emoji UTF-16、大小写、字段范围、替换与删除、行内格式、资产及块 ID 保留、结果上限、取消、原生一次撤销、只读、旧查询失效及不可见原生窗口中的窄宽布局。600,000 UTF-16 合成内容的扫描耗时单独记录在测试日志，不代表 WindowServer 帧率。原生截图检查包含正文、代码、表格与图片标题；使用临时进程和合成内容，不操作用户笔记。

真实长纸片滚动、中文输入法候选窗口、VoiceOver、跨应用聚焦仍待当前 Xcode 新版验收。

## 菜单材质统一（2026-09-10）

搜索面板、斜杠菜单、纸片操作面板及其颜色子菜单各使用一个 `EditorGlassSurface`。现有输入和列表放入 NSGlassEffectView.contentView；保留分隔线、描边和选择状态，去掉不透明底色。菜单玻璃独立于纸片纸感 / 通透选择，明暗随应用主题。系统减少透明度或增强对比度时，使用同一个内容实例回退原生实色背景；仅设置改变时更新，不轮询、不重建编辑器、不修改笔记。关闭窗口释放观察，保留的查找条随祖先隐藏。

离屏检查可验证结构、几何、输入和回退，不能验证 WindowServer 对实际桌面背景的折射效果。

玻璃接入后 Debug 构建及 10 项定向回归通过，包括搜索 / 替换撤销、斜杠菜单键入 / 删除 / IME、原生玻璃与实色回退中的控件身份与命中。
