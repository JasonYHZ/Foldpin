# 原生代码语言与悬浮工具条

当前高亮已接入成熟引擎，语言扩为 29 个选择，详见[语法引擎说明](syntax-engine.md)。下方 HTML 扫描器和手写检测器是升级前的记录，工具条交互约定继续有效。

2026-09-08：用户反馈 HTML 片段没有高亮，并提供 Notion 悬浮工具条参考，当前只要求语言选择和复制。

## 行为

- 随后的用户反馈要求支持自动识别。新代码块默认「自动识别」，覆盖 HTML、JavaScript、TypeScript、Swift、Python、JSON、SQL、Shell 的常见片段；工具条显示「自动 · HTML」等结果，证据不足显示「自动识别」并使用纯色。保留手动语言与明确纯文本选项，原笔记保留保存的模式。
- 鼠标位于代码块时，右上角出现语言菜单和复制图标。每个编辑器只复用一个原生工具条；操作绑定悬浮块的 UUID，即使光标在其他段落也不会改错块或复制错内容。
- 选择语言或自动模式立即更新高亮，保存到原块的 `language` 字段（自动为 `auto`，检测结果不另存），保留选区、滚动位置与原生撤销历史。输入三个反引号和 `html` 后按空格 / 回车，也可直接创建 HTML 代码块。
- 复制保留代码原文、缩进、换行和 Unicode；成功后短暂显示勾选图标。只读或组合输入期间不允许改变语言。原内容块菜单继续提供语言和复制入口。
- 工具条浮在代码右上方，不改变正文排版、不插入占位字符。长块随可见区域定位；离开代码或滚动后重新定位。明暗代码主题和中英文文案沿用现有即时更新机制。

## 实现边界

`CodeLanguageDetector` 最多取正文前 8,192 个 UTF-16 单元，用本机编译后的规则识别。字符串 / 注释中的示例不会成为其他语言的判据；含糊片段（例如 `let value = 1`）回退为纯文本。自动模式会在继续输入 / 粘贴后重新计算，手动选择始终优先。不是完整语言分类模型，不保证所有片段识别正确；不支持的语言仍可选纯文本。

`HTMLCodeHighlighter` 以 UTF-16 坐标扫描标签、属性、字符串、注释、DOCTYPE 与实体；注释和引号内的伪标签不再误着色。`script` 内默认 JavaScript，明确的 JSON 类型使用 JSON 高亮。样式通过现有 TextMate 作用域适配到内置或导入主题。

仍是本地短片段词法高亮，不执行 HTML，不加载 WebView、CSS 或第三方脚本；CSS、复杂模板语言和完整嵌套语法分析不属于本轮。保留 24,000 UTF-16 长度上限，超出时保持可编辑的纯色显示。

## 验证

### Java 与滚动闪烁修复（2026-09-08）

Java 已加入菜单、自动识别、java 围栏及原生高亮。自动识别比较包 / 导入、带修饰符的声明、方法签名和标准库调用等线索；含糊的 `int count = 1;` 仍可回退为纯文本。高亮支持关键字、类型、注解、方法、字符串 / 文本块、注释和数字。

闪烁的直接原因是每个 clip view bounds 通知先隐藏工具条，再在下一轮异步显示；工具条位于正文视图内，也会先随正文移动，再被定位代码移回。现在将它挂在 NSScrollView 上层，与 NSClipView 同级，转换 TextKit 几何并对齐 backing 像素。滚动通知只合并定位更新，保留显示状态；跟踪区域用 inVisibleRect 自动跟随视口，不在每次布局时删除重建。工具条自己转发指针变化，避免进入覆盖层被误判为离开代码。相同内容、语言和主题不重复更新标签与控件尺寸。

本轮 Xcode 构建和 10 项相关检查通过：Java 自动识别与高亮、源码 / 语言的 JSON 往返、java 围栏、原有自动模式 / 撤销 / IME，以及连续离屏滚动中保持可见、位置固定、跟踪区域复用、进入工具条不误隐藏和容器解绑。未操作实际运行窗口；真实鼠标滚轮、触控板惯性和菜单展开的流畅度仍待新版使用确认。
