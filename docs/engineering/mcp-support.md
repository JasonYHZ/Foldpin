# MCP 接入与实现记录

日期：2026-09-15。当前开发版本已接入 80 个工具，入口为 **设置 → 连接 AI 工具**。接口注册、权限和参数的完整清单见 [工具覆盖表](mcp-tool-coverage.md)，原始需求见 [开发方案](mcp-support-plan.md)。本次直接在 `main` 开发。

## 如何连接

1. 运行本次构建的 Foldpin，在设置中打开「连接 AI 工具」，启用 MCP。
2. 点击「授权客户端…」，填写一个易识别的名称，选择当前库的全部纸片或具体纸片／集合，并勾选需要的权限。默认只有文字读取权限。
3. 保存仅显示一次的访问密钥。客户端使用 **Streamable HTTP**，默认地址为 `http://127.0.0.1:51821/mcp`，请求头为 `Authorization: Bearer <访问密钥>`。
4. 客户端完成 MCP initialize 后，先调用 `foldpin_get_status` 获取授权库的 `libraryId`，再读取 `tools/list`。发现接口的 libraryId 可以传空字符串，其他工具须使用实际授权库 ID。

支持协议版本 **2025-11-25**。使用官方 Python MCP SDK **2.2.0** 和 TypeScript SDK **1.30.0** 完成真实回环网络连接测试；测试脚本分别为 `scripts/checks/mcp-client-python.py`、`scripts/checks/mcp-client-typescript.mjs`。这验证 SDK 互通，不等于所有 AI 客户端版本都经过验收。需要 OAuth、云端访问本机或仅支持 stdio 的客户端目前不能直接连接；不自动安装桥接软件，也不改写已有 Agent 配置。

端口修改前先关闭 MCP。端口占用时显示启动错误，可手动更换；不会自动绑定到其他网络接口。关闭 MCP 或退出 Foldpin 后停止监听。服务运行在 Foldpin 进程内，无额外后台进程。

## 已接入的能力

- 纸片列表、检索、分页读取、创建、副本、正文和块结构编辑；待办、行内格式、查找替换、表格、颜色、图标、收藏。
- 集合读取、新建、重命名、删除及成员调整；删除集合保留纸片。
- 显示／收纳／关闭、置顶／折叠／窗口位置尺寸、排列及撤销排列、打开收纳和设置。
- 最近删除与恢复、按固定 ID 列表彻底删除；不会将空列表解释为删除整库。
- 引用资源的分页读取；图片尺寸／标题、音频命名、音视频播放／暂停／定位／速度，以及录音开始／暂停／继续／完成。
- Markdown 文件导入、图片／音频／视频／附件导入；单张和批量 Markdown／HTML 导出，有资源时沿用 ZIP 打包，附件导出保留原始文件类型和名称。
- 复制正文／图片／块；一次性粘贴 Markdown、文字、Foldpin 结构块、图片或访达文件。复用结构引用时只接受当前授权纸片实际引用且可读的资源；附件粘贴另需资源权限。没有剪贴板持续监听。
- 主题、界面语言、纸片材质、快捷键、代码主题与代码底色、登录启动、帮助与本地反馈表单。
- 库位置查看／迁移／打开已有库／回默认位置、只读空间统计及大资源引用、指定纸片保存失败重试。
- 当前客户端操作查询／取消、幂等重放、正文变更记录及按 changeId 撤销／重做。

资源清理、隔离／恢复、历史压缩以及购买／恢复购买尚无已验收产品实现，**不注册占位工具**。远程图片下载、模型推理、转写和内置聊天也不由本次 MCP 服务补造。外部文件和导出目录须在本机系统面板中选择；当前不接受任意绝对路径、上传句柄或返回服务器文件下载链接。

## 权限与确认

每个客户端独立生成 256 bit 随机凭据，存于 Keychain；授权范围保存在应用自身偏好，不进入纸片库或 iCloud。可在设置撤销授权或更换密钥；工具不能读取密钥、修改授权或给自己加权限。会话 ID 只标识协议会话，不能替代凭据。

授权绑定库身份。打开其他库不会把原客户端授权自动转移过去。指定集合的授权随其当前成员解析；读取最近删除还需删除／恢复或彻底删除权限。新建纸片、集合管理、整体排列、空间扫描等整库操作要求全部纸片范围，界面明确说明。

权限可以组合：复制需要剪贴板写入和文字读取，带资源还需资源读取；粘贴需要剪贴板读取和编辑，带资源还需资源权限；录音启动需要录音及编辑；导出需要导出和文字读取，带资源还需资源权限；Markdown 文件导入保留创建及编辑权限要求。`tools/list` 按主要权限筛选，执行时仍检查这些组合条件。

彻底删除、开始录音、文件导入导出、外部打开、库位置变更、登录项变更、退出等操作先返回 `awaiting_user` 和 operationId，在 Foldpin 本机显示客户端、操作与目标纸片名称。确认后再次检查固定目标及版本；确认有效期五分钟。模型提交 `confirmed=true` 无效且被严格 schema 拒绝。系统目录选择、麦克风与登录项确认仍由 macOS 处理。

当前取消策略偏保守：关闭服务、撤销／轮换凭据、删除协议会话会取消所有尚未提交的 MCP 请求。已完成的保存、导出或导入不会因取消自动撤回；批量导入保留已成功项目并返回逐项结果。部分正在展示的系统面板需用户关闭，提交前仍会重新核对取消状态。

## 保存、撤销与失败语义

附件粘贴和空间扫描先返回 `executing` 与 operationId；客户端用 `get_operation` 查询，或用 `cancel_operation` 取消尚未提交的效果。需要本机确认的长任务先返回 `awaiting_user`，确认后同样查询操作状态。

普通写入须提供 `idempotencyKey`；修改已有纸片须附上最近读取的 `expectedRevision`。修订对完整结构文档计算，不只依赖正文修改日期。设置、集合及库位置分别提供自己的修订。工具不直接覆盖 notes JSON，不依赖当前鼠标或键盘焦点。

内容写入通过 `FoldpinCommandService` 进入既有 NoteStore 保存路径。已有桌面／收纳编辑会话复用同一个 NSTextView 和 UndoManager；无编辑器的纸片以数据事务处理。中文组合输入、表格编辑、图片标题／缩放、导入导出和库切换期间拒绝冲突写入。正常未保存编辑不能被覆盖；保存重试仅允许已出现保存错误的状态，并继续检查修订及编辑忙碌状态。

正文操作返回 changeId，当前客户端可在本次会话按此撤销／重做；后续人工编辑改变基线时返回 `revision_conflict`。窗口、元数据、文件导入导出不伪报为正文可撤销操作。原应用已有的窗口与媒体撤销行为保持不变。

幂等收据存于应用私有本机目录 `mcp-receipts`，不放入共享库。重复同一 key 和参数返回之前结果；同 key 换参数拒绝。创建／正文写入在保存前记下目标 ID 和内容哈希，崩溃后可核对已保存效果并恢复结果。其他中断且无法确认效果的操作返回 `interrupted`，不盲目再执行；应先核对实际状态再发新请求。该机制不承诺跨文件事务。

批量删除、恢复及窗口操作固定目标并逐项返回结果。导入部分失败不撤回成功项目。重启后的幂等结果可通过相同工具和 key 取回；`get_operation` 的 operationId 查询索引仅保留本次进程，最多约 1000 条。库完全不可用时操作查询也可能返回 `library_unavailable`。保存失败重试针对可读纸片；库级读取恢复继续使用应用已有恢复界面。

调用历史最多保留 100 条，只在内存存客户端、动作、状态和时间；不记正文、文件路径或凭据。幂等收据与调用历史分开，收据保留实际返回结果，可能含纸片标题和 ID。

## 实现入口

| 位置 | 职责 |
| --- | --- |
| `macOS/Foldpin/Core/MCP/MCPHTTPServer.swift` | IPv4／IPv6 回环 socket、HTTP 报文解析、尺寸及连接限制 |
| `MCPServer.swift` / `MCPCredentials.swift` | MCP 生命周期、会话、Keychain、速率和授权管理 |
| `MCPRegistry.swift` / `MCPTypes.swift` | 80 个工具的严格 schema、权限、错误、修订和收据 |
| `FoldpinCommandService.swift` | 固定目标、权限、保存、变更记录、审批和批量结果 |
| `MCPClipboard.swift` | 单次剪贴板快照、引用校验、复用资源导入器 |
| `macOS/Foldpin/AppDelegate.swift` | 将原生窗口、媒体、设置、存储及系统面板绑定到服务 |
| `macOS/Foldpin/MCPSettingsView.swift` | 设置、客户端范围与权限、本机审批窗口 |
| `macOS/Foldpin/Editor/NativeBlockEditor.swift` | 原编辑会话内命令写入、独立撤销组与媒体控制 |

监听仅绑定 127.0.0.1 和 ::1；明确 IPv6-only 防止双栈重复占用。Host 和有效 Origin 限制在本机端口，拒绝重复 HTTP 头、Transfer-Encoding、超长／多余请求数据。最多 16 个连接、15 秒连接超时、16 KiB 请求头、2 MiB 请求体；每客户端每分钟 120 次、全局 240 次请求。正文分页最多 100 块，资源每次最多 256 KiB；不建立事件推送通道，GET 返回 405。

协议依据：[MCP Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[MCP Tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。静态 Bearer 凭据是本机显式配置方案，不宣称实现 OAuth 授权服务器。

## 验证边界

已完成：核心回归、15 项 MCP 定向测试、官方 Python／TypeScript SDK 的真实回环网络测试，以及不可见原生窗口的编辑器身份、UndoManager、中文组合输入与设置排版检查。具体最终数量和构建结果见 [M1 验证记录](m1-validation.md)。SDK 测试使用临时库、内存假凭据和独立客户端，不读写个人 Agent 配置。

真实麦克风、系统导入导出面板、登录项注册、真实 iCloud 双机、Keychain 轮换交互和发行签名下的 App Sandbox 联网仍需实机验收。未操作用户真实纸片、录音设备或系统剪贴板。Debug 构建包含 `network.server` entitlement；通过构建不等于已完成 Mac App Store 审核或沙盒发行验收。
