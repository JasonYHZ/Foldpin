# 最近删除：彻底删除

2026-09-14 按用户要求加入。仅作用于已经进入「最近删除」的纸片。

- 单选：右侧纸片底部的「彻底删除」及右键菜单。
- 多选 / ⌘A：右侧「更多 → 彻底删除」，或右键选中纸片；只处理选中集合。
- 无选择：右侧显示「彻底删除所有」。针对整个最近删除，包含搜索 / 类型筛选当前没有显示的纸片。空列表时禁用。
- 确认框显示固定的目标数量和不可恢复 / 不可撤销说明；取消为默认按钮。确认期间新增的纸片不会加入目标，已经恢复的目标会被拒绝。

## 持久化和失败

`NoteLibrary.permanentlyDeleteNote` 复查内存条目属于最近删除、磁盘记录仍为已删、文件为普通文件且不是链接，然后移除 `notes/<UUID>.json`。没有操作系统废纸篓恢复入口。逐张处理，失败保留原条目与恢复能力；批量反馈成功和失败数量，不误报全部成功。

磁盘删除成功后将 NoteStore 置为终态：取消自动保存、禁用后续编辑 / 保存 / reload，并清空所持正文。窗口控制器释放编辑器、撤销记录和回调；AppDelegate 从控制器字典移除 UUID。旧异步回调不能重新写出纸片。

`library-kept-empty` 在删除前原子写入，用于保留用户主动清空后的空库状态；重启不自动创建替代空白纸片。新建仍正常可用。

本功能删除纸片记录，不是安全擦除工具。共享资产可能被其他纸片、剪贴板或它们的撤销记录引用，因此不清扫共享 assets、历史迁移备份和用户已导出的文件，避免破坏仍保留的内容；资源回收需独立处理完整引用关系。

## 验证

240 项 Swift 回归和 Debug 构建通过。新增测试覆盖只允许最近删除、正文文件消失、旧 store / 排队保存不复活、重启保持空库、主动新建、磁盘状态变化时拒绝、失败保留恢复及共享附件不受影响。

隔离原生窗口检查覆盖无选择 / 单选 / Command 多选 / 全选目标、搜索不缩小「删除所有」范围、部分删除保留剩余纸片、已恢复目标不被误删、控制器释放与清空后的空集合。测试仅使用临时笔记库；没有删除用户纸片。确认框的真实指针点击尚未实机验收。
